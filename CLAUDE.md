# OpenAnime-Desktops — Proje Kuralları

## Test ve doğrulama
- Test/doğrulama çalıştırmaları `pnpm run tauri dev` ile yapılır.
- `npm run dev`, `bun run dev` veya doğrudan `vite dev` ile test yapılmaz.
- `pnpm run tauri dev` çalışmıyorsa (pnpm kurulu değilse) durum kullanıcıya bildirilir; sessizce başka paket yöneticisine geçilmez.
